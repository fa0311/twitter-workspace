Memory holds principles, each stated so that it decides a case it has not seen. Incidents, dates, quotes, ids and commands do not
belong here: recipes and facts go to `REFERENCE.md`, rules to `CLAUDE.md`, history stays in git.

**Why:** the maintainer found the feedback notes useful but too tied to the cases they came from (2026-11-16, "もっと抽象的に出来ないか").
**How to apply:** when feedback arrives, find the principle behind it and fold it into the matching note instead of appending the
episode; keep a concrete anchor only where the principle alone would be ambiguous, and mark a reading of mine as mine.
Related: [[feedback-working-rules]].
